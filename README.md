# Personal Expense Data Analysis

Personal Expense Data Analysis (Excel)
Project Overview
This project uses Microsoft Excel to organize and analyze personal
financial transactions. The workbook contains a transaction dataset and
summary sheets intended to help explore income, expenses, budgets,
payment methods, banks, categories, and savings goals.
Workbook Structure
1. Dataset
The main transaction table contains fields such as: - Transaction ID and
Date - Year, Month, Quarter, and Month Number - Account and Bank -
Transaction Type (Income or Expense) - Category and Sub Category -
Payment Method, Merchant, and Description - Amount (₹) and Budget (₹) -
Savings Goal and Location - Status, Recurring, and Tax Deductible -
Balance After Transaction (₹)
The workbook also uses Excel formulas to derive month, quarter, and
month-number fields from transaction dates.
2. Sheet1
This sheet contains summary tables for exploring: - Income and
expenses - Monthly income vs. expenses - Expense totals by category -
Income by category - Transactions by bank - Savings goals - Transaction
types and amounts
3. Dashbord Layout
This sheet is reserved for the dashboard layout/design.
Tools and Skills
- Tool: Microsoft Excel
- Analysis techniques: Transaction categorization, aggregation,
  budget comparison, monthly summaries, and category-based analysis
- Excel concepts represented: Formulas, summary tables, and
  dashboard planning
Questions This Workbook Can Help Explore
- How much was recorded as income versus expenses?
- Which categories account for the largest expenses?
- How do income and expenses vary by month?
- Which banks and payment methods are used most often?
- How are transactions distributed across savings goals?
- How do recorded amounts compare with budgets?
How to Use
1. Open the Excel workbook in Microsoft Excel.
2. Review the Dataset sheet to understand the transaction fields.
3. Use the summary tables in Sheet1 to inspect the available
   breakdowns.
4. Review Dashbord Layout for the dashboard design area.
5. If adding or changing transactions, check that formulas and summary
   tables include the updated data; refresh any PivotTables if
   applicable.
Notes
- Currency values are shown in Indian rupees (₹).
- The workbook's summaries depend on the data and calculations
  currently stored in the file. Verify formulas, refresh summaries,
  and validate totals before using results for financial decisions.
- This README describes the workbook structure and intended analysis
  areas; it does not claim that every dashboard element or analytical
  question is fully automated.
